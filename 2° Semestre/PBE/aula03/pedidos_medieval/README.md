# Pedidos Medievais
Projeto full stack criado em aula de back

## Tecnologias
- Node.js
- VsCode
- JavaScripot
- JSON
- HTML

## Como testar
- Clonar este repositório
- ABrir com o  VsCode e em um terminal digitar os seguintes comandos
```bash
npm install
npm run dev
```
- Execute o arquivo cliente/index.html com Live server do VsCode
